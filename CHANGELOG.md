# Changelog

All notable changes to Voice Note Studio will be documented in this file.

## [4.0.0] - 2024-01-20

### Added
- Real-time speech transcription with Web Speech API
- AI text enhancement (filler word removal, grammar correction)
- Sentiment analysis for emotional tone detection
- Action item extraction from transcripts
- Recording library with save/load functionality
- Multi-format export (TXT, DOCX, PDF, Markdown)
- Dark mode toggle with persistence
- Keyboard shortcuts for power users
- WebSocket support for real-time enhancement
- Comprehensive API documentation

### Changed
- Improved UI with professional design
- Enhanced transcription accuracy
- Better error handling and user feedback

### Fixed
- WebSocket connection issues
- CSS loading problems
- Cross-browser compatibility

## [3.0.0] - 2024-01-10

### Added
- Dark mode support
- Keyboard shortcuts
- Responsive design

## [2.0.0] - 2024-01-01

### Added
- Recording storage
- Export functionality
- Search feature

## [1.0.0] - 2023-12-20

### Added
- Initial release
- Basic transcription
- Simple UI
