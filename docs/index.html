API Overview

The Voice Note Studio API provides programmatic access to all features including transcription, recording storage, and AI enhancement.

GET /api/health

Check server health status

POST /api/save-recording

Save a recording to the database

GET /api/recordings

Retrieve all saved recordings

Frequently Asked Questions

How do I improve transcription accuracy?

Speak clearly, reduce background noise, use a good quality microphone, and ensure you're in a quiet environment. Also, try to speak at a natural pace.

Is my data stored securely?

All data is stored locally on your machine. No data is sent to external servers except for CDN resources required for the interface.

Can I use this offline?

Currently, an internet connection is required for CDN resources. Offline mode is planned for future releases.
